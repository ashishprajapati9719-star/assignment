# Assignment 4: JavaScript Functions and HTML Divs & Attributes

## Aim
To practice JavaScript functions, arrow functions, default parameters, HTML div elements, attributes, and fixing HTML errors.

## Part 1: JavaScript – Writing Functions

### Tasks
1. Created a `greet()` function that returns a greeting message for Asha.
2. Created an arrow function `square()` to calculate the square of 6.
3. Created a `billWithTax()` function using a default tax rate of 18%.

### Files
- `task1.js`
- `task2.js`
- `task3.js`

### Expected Output

| Task | Output |
|---|---|
| Task 1 | Hello, Asha |
| Task 2 | 36 |
| Task 3 | 118 |

### Run Commands
```bash
node task1.js
node task2.js
node task3.js
```
